# Generative AI Course Projects

### 生成式 AI：文字與圖像生成的原理與實務

A collection of coursework, hands-on experiments, and personal projects developed for **Generative AI: Principles and Practices of Text and Image Generation (生成式 AI：文字與圖像生成的原理與實務)**, taught by **Professor Yen-Lung Tsai (蔡炎龍老師)**.

This repository documents my learning journey in generative artificial intelligence, from understanding fundamental concepts to building practical AI applications.

## About This Repository

This repository contains projects and assignments completed throughout the course, exploring how generative AI can be applied to solve real-world problems.

Rather than focusing only on model outputs, I aim to understand how AI systems are designed, how different techniques work together, and how applications can be improved through experimentation and iteration.

本專案庫整理蔡炎龍老師「生成式 AI：文字與圖像生成的原理與實務」課程中的作業、實作成果與學習紀錄，包含從 AI 基礎應用到實際系統開發的探索與嘗試。

## Projects

| Project | Key Concepts | Description |
|---|---|---|
| Travel Planning Chatbot | LLM Applications | A conversational assistant that recommends travel activities and destinations. |
| Student Regulations RAG | Retrieval-Augmented Generation | A question-answering system that retrieves information from student regulations. |
| Supplement Price Hunter | Tool Use, Multi-Agent Collaboration | An AI agent that searches product prices and uses a second agent role to review the results. |

*Projects will be added and updated as they are organized.*

## Technologies & Tools

- **Programming:** Python, Jupyter Notebook, Google Colab, HTML
- **LLMs:** OpenAI GPT-OSS and other generative AI models

## Learning Objectives

Through these projects, I aim to develop practical skills in designing AI workflows, integrating language models with external tools and data sources, evaluating model responses, and improving AI applications through testing and debugging.

Each project represents not only a completed assignment but also an opportunity to explore the capabilities and limitations of generative AI.
